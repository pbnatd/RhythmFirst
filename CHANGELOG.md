# Changelog

## 0.2.1

- добавлен запуск на macOS двойным нажатием на `Rhythm First.command`;
- launcher создаёт `.venv`, устанавливает зависимости и выбирает свободный порт;
- добавлены GitHub Actions и инструкция публикации в `vvgstt/RhythmFirst`;
- добавлена отдельная инструкция диагностики запуска.

## 0.2.0

- добавлена автоматическая оценка BPM с ручной корректировкой;
- исходный грув циклически продлевается до 8, 16 или 32 тактов;
- усилены различия между музыкальными стилями.
