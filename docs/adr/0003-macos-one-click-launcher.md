# ADR 0003: macOS launcher владеет локальным окружением и портом

Статус: принято

## Контекст

Rhythm First используется как локальное веб-приложение для демонстрации проекта. Ручной запуск сервера и открытие адреса создают лишние шаги. Фиксированный порт может вести к старому процессу или конфликтовать с другим приложением, а зависимости не гарантированно установлены на новом Mac.

## Решение

- пользователь запускает приложение двойным нажатием на `Rhythm First.command`;
- основной сценарий запуска расположен в `scripts/run_rhythm_first_macos.command`;
- launcher проверяет Python 3.11+, FFmpeg и ffprobe;
- локальное Python-окружение создаётся в `.venv`, зависимости устанавливаются из `requirements.txt`;
- launcher выбирает свободный loopback-порт и открывает адрес именно нового процесса;
- сервер работает только пока открыт процесс launcher и останавливается вместе с ним;
- `.venv` и пользовательские аудиорезультаты не входят в репозиторий.

## Последствия

Запуск для демонстрации сводится к одному действию и не зависит от заранее выбранного порта. Первый запуск требует интернета для установки Python-зависимостей, а Python и FFmpeg остаются системными prerequisites. Сообщения об их отсутствии показываются явно, а не скрываются.
