# Rhythm First

Rhythm First превращает короткую запись акустических барабанов в музыкальный эскиз с басом и клавишами. Исходная партия остаётся в миксе, а гармоническое направление задаёт пользователь.

## Что работает в версии 0.2.1

- запись через микрофон браузера с четырьмя долями отсчёта;
- загрузка готового аудиофайла;
- автоматическая оценка BPM с показом уверенности и ручной корректировкой;
- отдельный выбор длины исходной записи (4/8 тактов) и результата (8/16/32 такта);
- циклическое продление короткой барабанной партии до всей длины результата без пустого хвоста;
- три интерпретации: Indie rock, Neo-soul и Electronic;
- различающиеся ритмические рисунки и тембры баса/клавиш для каждого стиля;
- локальный синтез баса и клавиш без облачных API;
- сведение с исходной записью через FFmpeg;
- прослушивание общего микса и отдельных дорожек;
- скачивание результата.

Это проверка базового эффекта, а не финальная генеративная система. Авто-BPM может ошибиться в два раза из-за музыкальной неоднозначности, поэтому пользователь видит результат и может его исправить. Продление пока повторяет целую исходную запись: оно не придумывает филлы и переходы. Из одной ударной партии нельзя восстановить единственно правильную гармонию — продукт предлагает интерпретацию в выбранном стиле.

## Запуск

Требования: Python 3.11+, NumPy и FFmpeg (включая `ffprobe`).

### macOS — запуск двойным нажатием

1. Распакуйте архив проекта.
2. Дважды нажмите [`Rhythm First.command`](Rhythm%20First.command).
3. Не закрывайте открывшееся окно Terminal, пока пользуетесь приложением.

При первом запуске launcher сам создаст окружение и установит Python-зависимости, выберет свободный порт и откроет приложение в браузере. Если macOS блокирует файл, откройте **System Settings → Privacy & Security → Open Anyway**.

Подробная диагностика: [`docs/runbooks/macos-launch.md`](docs/runbooks/macos-launch.md).

### Ручной запуск

```bash
python3 -m app.server
```

После запуска открыть `http://localhost:8000`.

Другой порт:

```bash
RHYTHM_FIRST_PORT=4173 python3 -m app.server
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

## Следующие продуктовые шаги

1. Проверить авто-BPM и точки повторения на нескольких реальных записях акустических барабанов.
2. Добавить структуру песни: куплет, припев, бридж и маркированные места переходов.
3. Подключить LLM только как планировщик валидируемой структуры и пожеланий, а не как обработчик аудио.
4. После структуры — выбор инструментов и экспорт аккордов/плана партий.

Архитектурные решения описаны в каталоге [`docs/adr`](docs/adr/README.md).
